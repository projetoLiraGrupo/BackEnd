# HTTP Status Codes / Códigos de estado HTTP

## 1xx Informational / Informativo

| Code | EN | PT |
|------|----|----|
| 100 | Continue | Continuar |
| 101 | Switching Protocols | Mudança de protocolos |

## 2xx Success / Sucesso

| Code | EN | PT |
|------|----|----|
| 200 | OK | OK |
| 201 | Created | Criado |
| 202 | Accepted | Aceite |
| 204 | No Content | Sem conteúdo |
| 206 | Partial Content | Conteúdo parcial |

## 3xx Redirection / Redirecionamento

| Code | EN | PT |
|------|----|----|
| 301 | Moved Permanently | Movido permanentemente |
| 302 | Found (temporary redirect) | Encontrado (redirect temporário) |
| 304 | Not Modified | Não modificado |
| 307 | Temporary Redirect | Redirecionamento temporário |
| 308 | Permanent Redirect | Redirecionamento permanente |

## 4xx Client Error / Erro do cliente

| Code | EN | PT |
|------|----|----|
| 400 | Bad Request | Pedido inválido |
| 401 | Unauthorized | Não autenticado |
| 403 | Forbidden | Proibido |
| 404 | Not Found | Não encontrado |
| 405 | Method Not Allowed | Método não permitido |
| 409 | Conflict | Conflito |
| 410 | Gone | Removido |
| 415 | Unsupported Media Type | Tipo de média não suportado |
| 422 | Unprocessable Entity | Entidade não processável |
| 429 | Too Many Requests | Demasiados pedidos |

## 5xx Server Error / Erro do servidor

| Code | EN | PT |
|------|----|----|
| 500 | Internal Server Error | Erro interno do servidor |
| 501 | Not Implemented | Não implementado |
| 502 | Bad Gateway | Gateway inválido |
| 503 | Service Unavailable | Serviço indisponível |
| 504 | Gateway Timeout | Timeout do gateway |
